
# Output Module

## Objective

Present the discovered books in an organised,
readable, research-friendly format.

## Introduction

Mention:

- Country
- Performing arts discipline
- Search focus
- Number of verified results

## Book Information

Present the following fields:

1. Title
2. Author/editor
3. Publication year
4. Publisher
5. ISBN, if verified
6. Country or tradition discussed
7. Performing arts category
8. Academic classification
9. Brief description
10. Verification source
11. Access information

## Presentation

Use a table for the main results.

Provide a concise explanation of each book's
relevance to the user's research.

## Conclusion

Identify the most useful books for:

- Beginners
- Academic research
- Historical research
- Performance theory

Only make these recommendations when supported
by the available information.

## Final Rule

Never fabricate bibliographic information to
complete a requested number of results.
