
# Verification Module

## Objective

Check the bibliographic accuracy of every recommended
book.

## Verify

- Book title
- Author or editor
- Publication year
- Publisher
- ISBN, when available
- Country or tradition discussed
- Source URL

## Verification Sources

Prefer:

1. Publisher's official catalogue
2. National library catalogues
3. University library catalogues
4. WorldCat
5. Google Books

Use additional reliable sources when necessary.

## Verification Rules

Check that the source refers to the correct book
and not a similarly titled publication.

Distinguish between original publication and
later editions.

Do not invent missing information.

If strict_verification is ON:

Include only books whose core bibliographic
details can be corroborated.

If strict_verification is OFF:

Include potentially relevant books with clearly
marked unverified details.

## Access Information

Distinguish between:

- Open-access full text
- Library access
- Preview available
- Purchase available
- Access status unknown

Never claim a book is freely downloadable without
confirming its availability and usage permissions.
