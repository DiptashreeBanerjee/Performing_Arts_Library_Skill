
# Performing Arts Book Finder

## Project Overview

Performing Arts Book Finder is a modular LLM skill
designed to discover and recommend books associated
with performing arts in user-specified countries.

## Objectives

- Identify books based on country and discipline.
- Support academic and general reading preferences.
- Discover books across different performing arts.
- Verify bibliographic information.
- Provide structured recommendations.

## Modules

1. Country Module
2. Discipline Module
3. Book Discovery Module
4. Academic Filter Module
5. Verification Module
6. Output Module

## Configurable Switches

- Academic Books Only
- Historical Focus
- Traditional Performing Arts
- Contemporary Performing Arts
- Open Access Preference
- Strict Source Verification

## Technologies

- Markdown
- JSON
- HTML
- JavaScript
- GitHub

## Example Queries

- Find books on theatre in India.
- Find academic books on dance in Japan.
- Find books on puppetry in Indonesia.
- Find books on contemporary music in Nigeria.

## Usage

The SKILL.md file provides the main instructions.
The reference files contain individual modules.
The JSON configuration defines module activation
and feature switches.

An LLM application with skill-loading and search
capabilities is required to execute the workflow.
